# 百鬼一閃 Walk4 Prototype

俯瞰視点のバッサバッサ系アクション試作です。
プレイアブルキャラクターは「ユユ」。
必殺技は「月蝕ノ舞」。

## 今回の変更

- ユユの移動を4コマ歩行アニメに変更
- 正面・背面・横向きの移動をグリッド切り出し
- 右向きは左向きコマを反転して使用
- スプライトのチェック背景をできる範囲で透過処理
- カットインと月蝕ノ舞エフェクトは継続

## 操作

### スマホ
- 左下スティック：移動
- 右下「一閃」：通常攻撃
- 右下「月蝕」：ゲージ100%で必殺技

### PC
- WASD / 矢印キー：移動
- Space：一閃
- E：月蝕ノ舞

## 調整ポイント

ユユの表示サイズを変えたい場合は `script.js` の `drawYuyu()` 内の `scale` を調整してください。

```js
const scale = attackFlash > 0 ? 0.34 : 0.31;
```

歩行速度を変えたい場合は `getYuyuFrame()` 内の `time * 10` を調整してください。

```js
let col = player.moving ? Math.floor(time * 10) % 4 : 0;
```

## v2 攻撃スプライト修正版

- 攻撃スプライトの読み取りを **4×4 → 3×3** に修正
- コマ切り出し余白を強めに調整
- 攻撃スプライトの表示サイズを少し縮小
- 攻撃時の表示位置を微調整

### 修正意図
前回版は、攻撃素材のグリッド解釈が合っておらず、
コマ読み違いによる破綻が起きていた可能性が高いため、
3×3 前提で読む安定版に寄せています。

「ユユが斬っている感じ」を前に出すためのバランス修正版です。

### 難易度の違い
- やさしい：敵の湧きがかなり少なめ
- ふつう：標準
- むずかしい：敵が多め
- 百鬼：かなり激しく湧く
